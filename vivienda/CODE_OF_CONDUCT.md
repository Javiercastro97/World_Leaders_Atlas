# Código de conducta

Este proyecto existe para defender el derecho a la vivienda. Quienes participan en él (código, datos, moderación o debate) se comprometen a:

- Tratar a todas las personas con respeto, sin discriminación por origen, género, orientación, discapacidad, edad, religión, situación económica o de vivienda.
- **No exponer a personas afectadas.** No compartir nombres, domicilios, imágenes ni circunstancias de nadie sin su consentimiento expreso, ni siquiera en issues o PR.
- No acosar, señalar ni publicar datos de particulares, incluidas las personas propietarias o el personal de juzgados y administraciones.
- Discutir sobre datos con fuentes. Discrepar de las ideas, no de las personas.
- Respetar las decisiones de moderación y usar los canales previstos para recurrirlas.

**Aplicación:** las personas mantenedoras pueden editar o eliminar contribuciones y bloquear temporal o definitivamente a quien incumpla este código. Para informar de un incidente, escribe de forma privada a las personas mantenedoras (ver SECURITY.md) o usa el sistema de reportes privados de GitHub.

Basado en los principios del Contributor Covenant 2.1.
